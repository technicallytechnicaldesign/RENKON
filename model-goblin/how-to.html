01 / ROUTE

Choose how much evidence you have.

Both routes use the same Author. Start with the GLB-only route when you want a quick static presentation, then add KeyShot evidence when motion, camera, or material identity matters.

Fast path

GLB only

Use this for a static model, a quick review, or a presentation that does not need recovered KeyShot motion.

02 / BUILD

From source files to presentation.

The exported HTML is the deliverable. Keep the Author page separate: it is the workshop, not something an audience should receive.

Prepare the source files.

Give parts meaningful, unique names before export. Make sure the GLB opens in a trusted viewer. If you have AA03 or AA04 evidence, keep all three files from the same scene revision.

Pass: one GLB, plus zero, one, or two matching Goblin JSON files.

Load the Author.

Open Model Goblin Author + Exporter v0.6.1. Drop the GLB into the first source box. Add salvage and material JSON only when available.

Wait for: the preview reports ready and the Export button becomes available.

Set the presentation.

Write the title and subtitle, choose a background and starting visual mode, then set autoplay, loop, speed, and turntable direction. Keep captured camera enabled when AA03 contains the intended KeyShot view.

Default: Proxy is the safest general-purpose starting mode.

Choose audience permissions.

Expose only what helps the presentation: timeline, visual modes, Inspect orbit, part selection, and fullscreen are independent switches.

Rule: if a control needs explaining to the audience, consider hiding it.

Refresh and test the preview.

Press Refresh preview after changing settings. Test play, restart, Inspect mode, visual modes, selection, and fullscreen before export.

Important: Inspect pauses presentation playback by design.

Export and reopen the HTML.

Press Export presentation HTML. Open the downloaded file in a fresh browser tab and repeat the audience test. Send that HTML, not the Author or raw template.

Pass: refresh reopens the clean viewer with no import or authoring controls.
03 / LOOK

Pick a visual mode for the question.

These modes communicate structure and material intent. They are not intended to reproduce KeyShot rendering pixel for pixel.

Proxy

Material-family interpretation for a clean presentation. Tune finish strength.

Original GLB

Uses the baked materials carried by the source GLB.

Technical

Manual-style light, dark, or material-family color with adjustable edge contrast.

X-ray

Shows internal relationships with adjustable shell opacity and optional solid selection.

Toon

Simplifies form into lighting bands and outlines for readable shape communication.

Material IDs

Stable diagnostic colors for checking object-to-material assignment.

05 / FIX

Troubleshoot by symptom.

Model Goblin should fail with evidence. Read the status message and browser console before changing the source scene.

SymptomLikely boundaryNext action
Play does nothingNo useful AA03 tracks or camera samples, or an older export.Check the salvage JSON, then export again from v0.6.1.
Playback controls are hiddenThe viewer detected no useful animation.Use the static presentation intentionally, or rerun AA03 and inspect its duration, tracks, and camera samples.
Motion is tiny or enormousKeyShot scene bounds and GLB bounds disagree.Remove unrelated hidden geometry or isolate the intended model before running AA03.
AA03 reports a NoneType bounding-box failureAn older runner tried to sample a camera or another non-geometry target as geometry.Download the guarded runner above and rerun it. Missing bounds are skipped while camera samples remain captured.
Model looks wrong while orbitingRecovered motion and captured camera share the KeyShot frame.Use Presentation for playback. Inspect pauses motion before allowing orbit.
Proxy materials map incorrectlyDuplicate names or unmatched KeyShot and GLB paths.Switch to Material IDs, rename ambiguous parts, rerun AA04, and reload the JSON.
Viewer never appearsCorrupt or truncated HTML, or WebAssembly disabled.Compare file size, re-download or re-export, then read the browser console.
Privacy and offline behavior: the v0.6.1 Author and every presentation it exports contain the required Three.js and Draco runtime locally. Source files are read in the browser and embedded into the exported HTML. Model Goblin does not upload the GLB or JSON to a backend.
06 / SCOPE

Know what crosses the bridge.

The stable route is designed for rigid technical presentation, not renderer-perfect scene migration.

Works well

Rigid product presentation

  • Static GLB inspection
  • Rigid translation across registered descendant bodies and named turntables from AA03
  • Visibility and captured camera samples
  • Material assignments and browser proxies from AA04
  • Single-file audience presentation
Does not cross

Renderer-only behavior

  • Deforming geometry
  • Generic rotation orientation beyond named turntables
  • Material or environment animation
  • Motion blur, volumetrics, and renderer effects
  • Guaranteed pixel matching with KeyShot
  • Reliable mapping from duplicate or meaningless part names
